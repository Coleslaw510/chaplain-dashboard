How the numbers work
  • The personnel report often repeats a Soldier once for every physical-fitness or weapon-qualification date. The dashboard keeps one row per Full Name and uses the most recent Physical Fitness Test Effective Date (and that row’s AFT result) and the most recent Weapon Qualification Date (and that row’s qualification). Other fields take the first non-blank value.
  • Soldier Job Code drops a leading E or O (O56A becomes 56A). Component (officer vs enlisted) is taken from that prefix when present, otherwise from rank. Officers use Mandatory Removal Date / RCP as their expiration; enlisted Soldiers use ETS.
  • Home Assignment Grade Entry Date is shown as Date of Rank. Time in grade is measured to the data as-of date. Four years or more is flagged; six years or more is a stronger flag.
  • The address report is joined by Last Name + First Name matching the start of Full Name (SMITH + JOHN matches SMITH JOHN DEAN). Case and extra spaces are ignored. Home address, city, state and ZIP are combined into one address. Preferred phone, home email and BN Name come from that report.
  • Religion Code is translated with the standard DoD/USMC manpower religious-preference list (BB is Baptist Bible Fellowship, NC is Primitive Methodist Church, and so on). Unknown codes are shown as entered; if the report also has a short description, that is shown too.
  • Weapon qualifications all count as passing. Ranking is Expert (highest), then Sharpshooter, then Marksman.
  • AFT values are normalised to Passed or Failed. Evaluation currency is flagged after 12 months and more strongly after 15 months (or if the date is missing). Weapon qualification is flagged after 12 months.
  • Files are recognised by their header row, not their name. Column names are matched ignoring case, spacing and punctuation. A title row above the headers is skipped.
  • Everything runs in this file on your computer. Nothing is uploaded to a server. A “Save with data” file contains whatever you loaded — treat it with the same protection as the source reports.
